# Simple To-Do App (Kairo)

A clean, minimalist task management application built for Android. This project focuses on a distraction-free user experience, stripping away unnecessary bloat to deliver a fast and intuitive way to manage daily tasks.

## Core Features

* **Quick Task Entry:** Easily add new tasks from the home screen using the dedicated Floating Action Button (FAB).
* **Priority Categorization:** Assign priority levels (Low, Medium, High, Urgent) using a custom, horizontally scrollable color-coded interface.
* **Due Dates & Scheduling:** Attach specific dates and times to any task to stay on track.
* **Custom Repeating Tasks:** Set tasks to repeat daily, weekly, monthly, or yearly with a streamlined UI.
* **Distraction-Free UI:** A stripped-down, focused home screen that only shows what you need to get done today.
* **Modern Theming:** Full support for system-level Light and Dark modes.

## Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Architecture:** MVVM (Model-View-ViewModel)
* **Asynchronous Programming:** Coroutines & Flow

## Getting Started

1. Clone this repository to your local machine.
2. Open the project in **Android Studio**.
3. Allow Gradle to sync and download the necessary dependencies.
4. Click **Run** to build and install the application on your emulator or physical device.
